# Design system — "Light"

The second edition of Wecycle's visual language (October 2026). Tokens and
component overrides live in [`app/light.css`](../app/light.css), loaded after
`globals.css` in `app/layout.tsx`. The header of that file is the long version
of this page.

## Principles

1. **Space and type make the hierarchy, not boxes.** Group by proximity. A
   fill is for a control (a field, a track, a chip); a line is for where two
   scrolling regions meet. No bordered cards, no tinted boxes around icons.
2. **Apple's type system.** System font (SF Pro on Apple devices, Roboto on
   Android, then Geist). iOS text styles as classes:

   | Class            | Size / leading | Weight |
   |------------------|----------------|--------|
   | `.t-large-title` | 34 / 41        | 700    |
   | `.t-title1`      | 28 / 34        | 700    |
   | `.t-title2`      | 22 / 28        | 600    |
   | `.t-title3`      | 20 / 25        | 600    |
   | `.t-headline`    | 17 / 22        | 600    |
   | `.t-body`        | 17 / 22        | 400    |
   | `.t-callout`     | 16 / 21        | 400    |
   | `.t-subhead`     | 15 / 20        | 400    |
   | `.t-footnote`    | 13 / 18        | 400    |
   | `.t-caption`     | 12 / 16        | 400    |
   | `.t-caption2`    | 11 / 13        | 400    |

   Bold is for titles of 28px and up; anything at reading size is semibold at
   most. Large figures (a price, a count) use `.t-figure`: weight 300.
3. **A mono voice for metadata.** `.t-label`: 11px, uppercase, SF Mono. Eyebrows,
   badges, counters. Inline uppercase styles in components use the same voice.
4. **One ink, one green.** Primary buttons are ink (`--ink`, #111110) with white
   text. Wecycle green (`--brand` for fills and icons, `--brand-ink` for text)
   marks a link, a success or a selection. Status colours appear as a 6px dot
   beside a word, not as a tinted button.
5. **Thin icons.** Phosphor, LIGHT weight, through `lib/icons.tsx`, which keeps
   the old Lucide names working. A selected state switches to the FILL weight
   (the tab bar does this). New code can pass `weight` directly. Emoji in option
   data render as glyphs through `<EmojiGlyph>`.

   **The exception is the category strip on Home**, which keeps its voxel renders
   (`public/icons/categories/*.webp`, owner's call, 18 Oct 2026). The tiles have
   no plate at rest; only the selected one gets a soft box. "All" is drawn in
   the same voxel style by [`scripts/make-voxel-all.py`](../scripts/make-voxel-all.py).
6. **Lighter motion.** Same five duration tokens (`lib/motion.test.ts` still
   enforces them). The snappy curve no longer overshoots; the bouncy one
   overshoots about 4%; presses scale to 0.97.

## Colour and contrast

All text colours clear WCAG AA against `--bg-inset` (#F4F4F2), the darkest light
surface: primary 17.2:1, secondary 6.1:1, muted 4.9:1, brand-ink 4.9:1.
`--text-quaternary` is for decoration only, never text.

## Gradients and grain

The liquid-marble textures from our social posts, generated by
[`scripts/make-textures.py`](../scripts/make-textures.py) into
`public/textures/`:

- `moss`, `ember`, `prism`, `violet`: the loud post palettes.
- `*-soft`: the same palettes blurred and veiled toward white on the left,
  for cards that carry type. At least 5:1 for ink text across the left 70%
  (the script's output was measured).
- `sunset`, `mist`, `meadow`: calm blooms for large light areas.
- `grain.png`: a 160px noise tile laid over any of them with
  `mix-blend-mode: overlay`.

Use them with `.tex .tex--moss` (etc.), which adds the grain on `::after`.

Free tools that make the same look by hand: [fffuel ffflux](https://www.fffuel.co/ffflux/)
(fluid gradients), [fffuel gggrain](https://www.fffuel.co/gggrain/) (grain) and
[Haikei](https://haikei.app/). The script exists so the textures are
reproducible and versioned with the app:

```bash
python3 scripts/make-textures.py
```

## Native apps

Everything here ships to the web on deploy. The iOS and Android apps bundle the
web build, so they pick it up at the next IPA/AAB. `capacitor.config.ts` and
`NativeInit.tsx` now use #FFFFFF for the splash and status bar, matching
`--bg-base`.
